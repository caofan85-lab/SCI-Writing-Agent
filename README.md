# SCI-Writing-Agent

An AI-agent-based workflow for scientific writing, literature mining, and plant genomics research.

## Overview

SCI-Writing-Agent is designed to assist researchers in preparing high-level scientific manuscripts, especially in plant genomics and transcriptomics studies.

## Core Functions

- Automated literature reading and summarization
- Local knowledge base construction (RAG)
- AI-assisted Discussion writing
- Figure–text consistency checking

## Agent Architecture

The system consists of three main agents:

1. Literature Summary Agent  
2. Discussion Writer Agent  
3. Figure Consistency Check Agent  

These agents collaborate through a modular workflow to support complex research writing tasks.

## Application Scenario

This workflow has been applied to the preparation of a hexaploid *Trifolium ambiguum* genome manuscript.
