# SCI-Writing-Agent

An AI-agent-based workflow for scientific writing, literature mining, and plant genomics research.

---

## 🔬 Overview

SCI-Writing-Agent is an AI-driven system designed to assist researchers in preparing high-level scientific manuscripts, particularly in plant genomics and transcriptomics.

The system integrates literature knowledge, experimental results, and structured reasoning to support efficient and consistent scientific writing.

---

## ⚙️ Core Functions

- 📚 Automated literature reading and summarization  
- 🧠 Local knowledge base construction (RAG)  
- ✍️ AI-assisted Discussion writing  
- 🔍 Figure–text consistency checking  

---

## 🧩 Agent Architecture

The system adopts a modular multi-agent design:

1. **Literature Summary Agent**  
   Extracts scientific questions, methods, and discussion logic from papers  

2. **Discussion Writer Agent**  
   Generates structured Discussion sections using retrieved knowledge  

3. **Figure Consistency Check Agent**  
   Identifies inconsistencies between manuscript text and figures  

---

## 🔄 Workflow

This pipeline enables end-to-end AI-assisted scientific writing.

---

## 🌱 Application Scenario

This workflow has been applied to the preparation of a hexaploid *Trifolium ambiguum* genome manuscript, including:

- Literature logic extraction  
- Discussion section generation  
- Figure–text consistency verification
